# ORB8 Next Starter

Next.js App Router + TypeScript + Tailwind CSS starter for the ORB8 marketing site.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Current scope

- Static marketing site
- No auth
- No database
- No backend
- Initial ORB8 visual system and page structure
- Ready for React Bits motion components later
